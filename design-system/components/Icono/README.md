Ícono de la serie propia Siles (37 glifos); úsalo en servicios, botones y listas — nunca mezclado con otras familias ni con emojis.

```jsx
<Icono nombre="automatizacion" tamano={40} />
<Icono nombre="flecha" tamano={20} titulo="Siguiente" />
```

- El trazo hereda `color`; el acento usa `--icono-acento`, que cambia solo con `data-theme="dark"`.
