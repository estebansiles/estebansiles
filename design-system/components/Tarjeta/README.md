Tarjeta recta con filete para servicios, casos y pasos de proceso.

```jsx
<Tarjeta icono="automatizacion" titulo="Automatización" pie={<Enlace href="#">Ver más</Enlace>}>
  Casi todo se puede automatizar. Empiezo por lo que más tiempo te quita.
</Tarjeta>
```

- `variante="hundida"`: fondo-suave sin borde.
- Nunca sombras, radios ni borde de color a la izquierda.
