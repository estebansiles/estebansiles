Banda de ancho completo con degradado de marca o motivo gráfico; el contenido va en un bloque liso.

```jsx
<Franja fondo="marca"><Titulo nivel={2}>Empieza por una llamada</Titulo></Franja>
<Franja fondo="trama" />
```

- `marca` (verde-1 a verde-2) para cierres y llamadas a la acción; `profundo` (tinta a verde-1 profundo) para pausas oscuras.
- `trama` y `lineas` son motivos planos sobre `fondo`, para separar secciones sin degradado.
- Una franja con degradado por página. Nunca texto suelto sobre el degradado.
