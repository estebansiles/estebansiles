Indicador de una cifra con su variación; la barra de marca arriba marca el bloque.

```jsx
<Metrica etiqueta="Ingresos del mes" valor="₡2 825 000" cambio="12 %" direccion="sube" nota="Frente al mes anterior" />
```

- La variación se lee con una palabra (Sube, Baja), nunca solo con color.
- Un indicador por fila; las cifras van con separador de miles con espacio.
