Contenedor de sección de página (sl-seccion + sl-contenedor); úsalo para cada bloque de una página o propuesta.

```jsx
<Seccion><Titulo>Servicios</Titulo>…</Seccion>
<Seccion tema="oscuro"><Titulo>Agenda una llamada</Titulo></Seccion>
```

- `tema="oscuro"` cambia todos los tokens de función dentro del bloque.
- `alterna` usa fondo-suave para separar bloques consecutivos.
