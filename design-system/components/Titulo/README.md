Título de bloque con antetítulo opcional y la firma de la marca; úsalo para abrir cada sección (uno con firma por bloque).

```jsx
<Titulo nivel={2} antetitulo="Servicios" bajada="Te acompaño desde la estrategia hasta la implementación.">
  Lo que hago
</Titulo>
```

- Mayúscula solo en la primera letra y nombres propios.
- `firma={false}` para títulos secundarios dentro del mismo bloque.
