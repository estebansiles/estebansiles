Patrón de red de Siles como fondo de portada (hero, portada de propuesta o de presentación); una sola vez por pieza, con el texto dentro de un bloque liso.

```jsx
<Patron alto={520} semilla={3}>
  <Titulo nivel={1} tamano="display" antetitulo="Transformación digital">Todo se puede transformar</Titulo>
</Patron>
```

- Líneas en gris, nodos cuadrados y un único nodo en verde-2.
- `tema="oscuro"` para portadas en tinta.
- Nunca texto directamente sobre las líneas; nunca dos patrones en una misma pieza.
