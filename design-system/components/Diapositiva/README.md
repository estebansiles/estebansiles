Lámina 16:9 para propuestas y presentaciones, con logo y pie de página fijos.

```jsx
<Diapositiva tema="marca" titulo="Alcance por fases" pie="IVA 13 % aparte" numero="03"><Pasos pasos={[...]} /></Diapositiva>
```

- Una idea por lámina. Los montos llevan moneda y el IVA se aclara en el pie.
- `tema="marca"` solo en portada o cierre: el contenido va en bloque liso.
- `tema="oscuro"` para cambios de ritmo en la presentación.
