Fotografía de marca con tratamiento duotono (tinta y verde) para que la imagen lleve color de marca.

```jsx
<Imagen src="/_blob/foto-id" alt="Esteban en reunión con cliente" proporcion="4 / 5" pie="Reunión de diagnóstico" />
```

- `duotono` (predeterminado): escala de grises multiplicada con el degradado profundo. Así la foto no se ve plana.
- `natural` solo cuando el color de la foto es el mensaje.
- Usar fotos propias o con licencia. Esquinas rectas. Texto alternativo siempre.
