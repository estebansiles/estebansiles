Secuencia numerada de pasos o fases; el paso activo se marca con acento sólido y filete de realce.

```jsx
<Pasos activo={1} pasos={[{etiqueta:'Fase 1',titulo:'Diagnóstico',texto:'Revisamos procesos y datos.'},{etiqueta:'Fase 2',titulo:'Diseño'},{etiqueta:'Fase 3',titulo:'Implementación'}]} />
```

- Usar en `Diapositiva` y en la sección de método del sitio.
- Tres a cinco pasos. El paso activo solo cuando el lector está en una fase concreta.
