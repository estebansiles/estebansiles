# UI kit · Sitio web de Siles Comunicación

Composición de referencia del sitio de la consultora, construida solo con los componentes del sistema.

**Aviso:** no se entregó código ni diseño del sitio actual (el repositorio `estebansiles/estebansiles` solo contiene un README de perfil). Estas pantallas aplican las reglas de marca; no replican un sitio existente. Reemplazar por la recreación fiel cuando haya fuente.

Pantallas (clic en la navegación):
- **Inicio** — portada con Patron, servicios en Tarjeta, proceso en 4 pasos, bloque oscuro con llamada a la acción.
- **Servicios** — Ficha de filtro, Pestanas, detalle con lista de verificación y panel de plazo.
- **Cotización** — documento con Logo, Cotizacion (IVA 13 % en fila aparte), Menu de exportar y Notificacion.
- **Contacto** — formulario con validación (Aviso de éxito, error en Campo) y Dialogo para agendar.

Archivos: `Encabezado.jsx`, `Pie.jsx`, `Inicio.jsx`, `Servicios.jsx`, `VistaCotizacion.jsx`, `Contacto.jsx`, `index.html`.
