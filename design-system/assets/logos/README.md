# Logos

Logo completo (SILES + barra + COMUNICACIÓN) e isotipo (S + barra), cinco versiones de cada uno, con los colores dentro del SVG (se muestran con `<img>`). Completo siempre que quepa; isotipo en avatares, favicon y barras de aplicación.

- `siles-logo-color.svg`, `siles-isotipo-color.svg` — letras tinta `#1E2020`, barra verde-1 `#008C99`. Sobre blanco; versión por defecto.
- `siles-logo-tinta.svg`, `siles-isotipo-tinta.svg` — todo en tinta. Sobre blanco.
- `siles-logo-verde.svg`, `siles-isotipo-verde.svg` — letras verde-1, barra tinta. Sobre blanco.
- `siles-logo-blanco.svg`, `siles-isotipo-blanco.svg` — letras blancas, barra verde-1. Sobre tinta.
- `siles-logo-blanco-pleno.svg`, `siles-isotipo-blanco-pleno.svg` — todo en blanco. Sobre verde-1 o fotografía.
