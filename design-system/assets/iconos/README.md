# Iconos

Serie propia de 37 íconos: línea 1.5 sobre retícula 24, extremos rectos, uniones en ángulo y un único acento sólido. Cada ícono viene en dos archivos con los colores dentro del SVG (se muestran con `<img>`; no heredan `color`):

- `<nombre>.svg` — trazo tinta `#1E2020`, acento verde-1 `#008C99`. Sobre blanco y fondo-suave.
- `<nombre>-blanco.svg` — trazo blanco `#FFFFFF`, acento verde-2 `#00D1B1`. Sobre tinta.

Para que el trazo tome el color del texto y el acento cambie con el tema, usar el componente Icono.
